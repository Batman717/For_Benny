# Heart Reel Project ❤️

A recreated version of the heart/floating-message effect shown in the Instagram Reel.

## Files
- `index.html` — page structure
- `style.css` — dark starry background, glowing heart and animations
- `script.js` — heart click, particles, floating messages and audio controls
- `sooong.mp3` — the song used by the page

## Run
Just double-click `index.html` and open it in a browser.

The included `sooong.mp3` is loaded automatically. The song starts after the first heart click because browsers generally block sound autoplay.

## Customize
Edit the `messages` array at the top of `script.js` to change the floating phrases.
